# Starlit Timeline Editor Web 🌟

アンブローズ・スターリット制作のブラウザベース動画編集アプリケーション

## 特徴 ✨

### コア機能
- ✅ **キーフレームアニメーション** - 位置、回転、不透明度、スケールをアニメーション可能
- ✅ **動画書き出し** - 連番PNG書き出し対応
- ✅ **エフェクト機能** - 映画風レターボックス、カラーグラデーション
- ✅ **素材管理** - ドラッグ&ドロップ対応のエクスプローラー
- ✅ **チョコレート&ビスケット** - WPF版から移植した美しいデザインテーマ
- ✅ **音声素材対応** - MP3/WAV/OGG音声ファイル、音量調整、波形表示
- ✅ **トランジション機能** - 9種類のトランジション効果(フェード、ワイプ、スライドなど)

### 対応素材
- 🖼️ 画像 (JPG, PNG, GIF, WebP)
- 🎬 動画 (MP4, WebM)
- 🎵 音声 (MP3, WAV, OGG) - **NEW!**

## セットアップ方法

### 1. ローカル開発環境
```bash
# シンプルなHTTPサーバーを起動
python -m http.server 8000
# または
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開く

### 2. GitHub Pagesでの公開

1. GitHubリポジトリを作成
2. このフォルダの全ファイルをリポジトリにプッシュ
3. Settings > Pages > Source を `main` ブランチに設定
4. `https://username.github.io/repository-name/` でアクセス可能に!

## 使い方 📖

### 基本操作

1. **素材の追加**
   - 左サイドバーの ➕ ボタンをクリック
   - または素材エクスプローラーに直接ドラッグ&ドロップ

2. **タイムラインに配置**
   - 素材をタイムラインにドラッグ&ドロップ
   - クリップをドラッグして位置調整

3. **プロパティセクションの開閉** **NEW!**
   - トランジション、音声、ループ、トランスフォームの各セクションをクリックで開閉可能
   - ▼アイコンが折りたたみ状態を示します

4. **キーフレーム設定**
   - クリップを選択
   - プロパティパネルで値を変更
   - 💎 キーフレームボタンをクリックしてキーフレームを追加
   - 時間を移動して別の値を設定→自動的にアニメーション!

5. **エフェクト適用**
   - 右サイドバーのエフェクトパネルで設定
   - チェックボックスでオン/オフ切り替え

6. **書き出し**
   - 書き出し範囲を設定
   - メニュー > 書き出し > 連番PNG書き出し

### ショートカットキー

- `Space` - 再生/一時停止
- `Delete` - 選択クリップを削除
- `Ctrl+Z` - 元に戻す
- `Ctrl+Y` - やり直し
- `Ctrl+Shift+D` - クリップを分割

## エフェクト詳細 ✨

### 🎬 映画風レターボックス
- 太さ調整 (0-200px)
- 色調整 (任意の色)
- シネマティックな雰囲気を演出

### 🌈 グラデーション
- 上部の色設定 (デフォルト: 黄色)
- 下部の色設定 (デフォルト: 青)
- 不透明度調整 (0-100%)

### 🎞️ トランジション効果 **NEW!**
各クリップにイン/アウトトランジションを設定可能:
- **なし** - トランジションなし
- **フェード** - 不透明度による滑らかなフェード
- **ディゾルブ** - フェードと同様の効果
- **ワイプ(左/右/上/下)** - 指定方向からワイプ
- **スライド(左/右)** - 画面全体がスライドイン/アウト

トランジション時間は0.1秒～クリップ長の半分まで調整可能

### 🔊 音声機能 **NEW!**
- 音声ファイルの再生とタイムライン表示
- 音量調整 (0-100%)
- 波形の視覚的表示
- 動画素材の音声も制御可能

## 技術仕様

- **フレームレート**: 30 FPS
- **デフォルト解像度**: 1920x1080
- **対応ブラウザ**: Chrome, Firefox, Edge (最新版)
- **必要な機能**: Canvas API, File API

## 制限事項

- MP4書き出しはブラウザの制限により未対応(連番PNGを推奨)
- 大きなファイルはメモリ使用量が増加する可能性あり
- テキストレイヤーは開発中
- トランジションは連番PNG書き出しにも適用されます
