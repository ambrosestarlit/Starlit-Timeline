ブラウザで動作する高機能タイムラインビデオエディタ - **JK丸ゴシックフォント対応版** ✨

## 🎨 新機能: カスタムフォント対応！

この版では **JK-Maru-Gothic-M.otf** フォントを全UIに適用しています！
- 丸みを帯びた優しいデザイン
- 日本語に最適化された美しい表示
- すべてのボタン、ラベル、テキストに適用

## ✨ 主な機能

### 📦 素材管理
- **複数ファイルインポート**: 画像・動画・音声対応
- **フィルタリング**: タイプ別に素材を整理
- **ドラッグ＆ドロップ**: 直感的な操作

### 🎬 タイムライン編集
- **マルチトラック**: 複数のビデオ/オーディオトラック
- **キーフレームアニメーション**: 位置・スケール・回転・不透明度
- **After Effects風UI**: 階層的なプロパティ表示
- **トランジション**: フェード・スライドエフェクト
- **ズーム機能**: タイムラインの拡大縮小

### 🎨 トランスフォーム
- **位置調整** (X/Y座標)
- **スケール変更** (1-500%)
- **回転** (0-360°)
- **不透明度** (0-100%)

### 🔊 音声機能
- **音量調整** (0-200%)
- **オーディオトラック**: 専用レイヤー
- **ループ再生**: 繰り返し設定

### 💎 キーフレーム
- **線形補間**: スムーズなアニメーション
- **ビジュアルインジケーター**: キーフレーム状態を表示
- **簡単追加/削除**: ワンクリック操作

## 🚀 使い方

### インストール

```bash
# 1. ファイルを展開
unzip StarlitTimelineEditor_JK_Font.zip

# 2. ブラウザで開く
# index.htmlをダブルクリック or
python -m http.server 8000
# → http://localhost:8000 にアクセス
```

### 基本操作

1. **素材追加**
   - 「📁 素材追加」ボタンをクリック
   - 画像/動画/音声ファイルを選択

2. **クリップ配置**
   - 素材をドラッグしてトラックにドロップ
   - 配置位置で開始時間が決定

3. **プロパティ調整**
   - クリップをクリックして選択
   - 右サイドバーでプロパティを編集

4. **キーフレーム設定**
   - 💎 ボタンをクリックでキーフレーム追加
   - タイムラインを移動して値を変更

5. **再生**
   - ▶️ ボタンで再生/停止
   - タイムラインをドラッグで位置変更

## 📐 AE風プロパティUI

After Effectsのような階層的なプロパティ表示：

```
📐 トランスフォーム ▼
  ▶ 📍 位置         0, 0 💎
  ▶ 🔍 スケール    100% 💎
  ▶ 🔄 回転          0° 💎
  ▶ 👁️ 不透明度    100% 💎
```

- **▶/▼**: プロパティの展開/折りたたみ
- **💎**: キーフレームインジケーター（オレンジ=設定済み）
- **値表示**: 現在の値を常時表示
